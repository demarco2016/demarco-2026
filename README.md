# demarco-2026
DEMARCO 2026 - Project Big Potential Tracker

## Reel (1080×1920, 30s)

`reel/` holds a vertical reel in the same style as `index.html`: golden captions that light up word by word, plus golden wipe transitions.

```bash
cd reel
npm install
npm run dev      # live preview at http://localhost:5173
npm run export   # renders out/reel.mp4 (needs ffmpeg)
```

The title, captions and timings are at the top of the script in `reel/index.html`.
